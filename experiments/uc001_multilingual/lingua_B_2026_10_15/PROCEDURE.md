# Lingua B — frozen procedure, 2026-10-15

One owner-approved CPU-only investigation; no production component selection.
The immutable 30-minute window includes metadata, preparation, acquisition,
isolated installation, loading and both passes. No reset, retry or fallback.

The 25 fixtures are 24 new controls plus exposed C6. They contain 24 distinct
text strings: the Velo pair intentionally changes country only. Two fixed passes
produce 50 measurements, not 50 independent examples. Expectations are AI-assisted,
not qualified linguistic review. No held-out file is opened or used to construct them.

After publisher/hash/license/compatibility and resource preflight, acquire the
single wheel once; no test extra, runtime dependencies, source build or upgrade.
Use a new virtual environment under the ignored run directory. Do not alter the
application environment. Record all acquired body bytes (metadata/license/wheel)
and on-disk logical and allocated scratch, including retained wheel and environment.

Use all publisher languages, default high-accuracy mode and default relative
distance, without tuning. Only original text goes to Lingua. Country/preferences
are fixture context for a separately labelled contract review, never detector input.
For each fixed record call ranked confidence then mixed-span detection, at most
100 classification calls total. Initialization/configuration is recorded separately.
Save and fsync every completed API operation and record immediately. An attempted
call is counted before invocation. Classifier mistakes do not stop the fixed sample.

Capture import, builder and first-record times separately; cold target is import +
builder + first record <=5s. The first pass has lazy model/cache effects: it is not
25 independent cold starts. Pass 2 reuses the same detector in identical order;
report its nearest-rank p95 over 25 records, target <=100ms. No cache eviction is
performed; actual library cache occupancy/misses are not exposed or measured.
Report ranking and span times separately, full-output repeat equality, raw clear
label correctness and mixture-component diagnostics. Rank scores are advisory,
not calibrated reliability. No top-ranked label alone certifies ambiguous language.

Record raw detector hypotheses, frozen expected contract routes and a subsequent
AI-assisted review separately. No application router, request interpreter,
normalizer, translator, renderer or unchanged Qwen scorer is executed; do not
invent repaired C6 output. A preference/meaning mapping derived from fixture
expectations is not observed application behaviour. Any clear required label
error rejects the label screen. Ambiguity/route risks remain explicit regardless
of a clear-label pass. No lost-constraint or translation success can be inferred.

A supervisor enforces the original deadline, two-CPU affinity/thread environment,
1 GiB aggregate owned RSS and 1 GiB additional scratch. Sample owned descendants
and RSS every 50ms and scratch every 250ms; record sampling limitations. Check
cgroup headroom alongside MemAvailable; require 1 GiB allowed RSS plus 512 MiB
reserve and at least 1 GiB scratch plus 512 MiB disk reserve before acquisition.
Include preparation-process high-water RSS where available. Stop operational,
package, time or resource failures immediately, preserving partial results; stop
only the owned process group after verifying its live PID/start ticks. No unrelated
process is stopped. Do not retry a killed/incomplete detector operation.

Network access is used only for the pinned publisher metadata/license/wheel.
After installation, the detector worker denies Python socket/network audit events;
Lingua is CPU-only. No LLM, GPU, paid provisioning or external text submission.
Preserve artifacts/results at closeout. Removal is not part of this investigation;
any future cleanup must target only this isolated directory after evidence review.
DESIGN and qualified linguistic validation remain pending.
