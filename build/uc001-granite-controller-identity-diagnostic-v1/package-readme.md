# Scoped unknown-child identity diagnostic — NOT AUTHORIZED / NOT EXECUTED

This separate package collects identity/path evidence for unexpected children
returned beneath the two verified scoped parents. Unknown children receive
query-only handles and are never terminated or accepted as helpers by this
diagnostic. A system image path is only an observation. The expected edge remains
exactly launcher → interpreter; any additional edge still fails.

All previous Windows attempts are consumed and preserved. This package grants no
execution permission. A later explicit owner authorization is required before
using `Run-IdentityDiagnostic.ps1 -OwnerAuthorized`. The switch records that later
approval; it does not obtain approval.

Use only a fresh `granite-controller-identity-diagnostic-v1` directory and the
approved separate Granite Python 3.12.11 environment. The runner checks the
externally supplied manifest hash, exact package files, helper hashes and inactive
native-acquisition template before one harmless ownership diagnostic. It prints
and retains a fresh sibling `ownership-identity-diagnostic-<GUID>` result directory.
On any failure, preserve its complete output and stop without fixes or retry.

PID/creation/parent/membership/path evidence remains subject to native query and
revalidation limits. Disappearance, PID reuse, an unavailable path or unknown
membership never establishes a helper role or successful ownership. No names or
paths are whitelisted. No machine-wide process inventory is emitted.

Toolhelp supplies no creation identity: binding after open cannot rule out reuse
between snapshot and open. Native open error 87 is recorded as not found/invalid
PID, without proving disappearance. Raw exit code 259 remains active-or-exit-code
ambiguous. Query handles add no termination authority; existing private-Job cleanup
is unchanged.

Acquisition, configure/build, glslc, GPU probes, model/server startup and inference
remain unauthorized. Preserve original packages, failed attempts and frozen
Granite settings unchanged.
